    <h2>The Idea</h2>
    <p>
      Setting up an Appwrite backend for a new project usually means a lot of manual steps; creating projects, adding databases, configuring storage, etc and replicating and syncing across different environments. The idea behind this is to take all of those repetitive tasks and codify them. With this approach, the backend can be ready to go in one shot, freeing developers from Appwrite resource setup and letting them focus on building their app.
